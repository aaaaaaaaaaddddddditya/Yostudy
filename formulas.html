Mathematics Formulas

Arithmetic

Simple Interest Formula

Formula:
SI = (P × R × T) / 100
Where:

P = Principal, R = Rate per annum, T = Time in years

Example:

If P = ₹1000, R = 10%, T = 2 years → SI = ₹200

Percentage Formula

Formula:
Percentage = (Part / Whole) × 100
Shortcut:

Move decimal 2 places to the right and add %

Example:

25/100 × 100 = 25%

Profit and Loss

Profit %:
((SP - CP) / CP) × 100
Loss %:
((CP - SP) / CP) × 100
Memory Trick:

Higher Selling Price = Profit | Higher Cost Price = Loss

Average Formula

Formula:
Average = Sum of all values / Number of values
Example:

Average of 10, 20, 30 = (10+20+30)/3 = 20

Ratio and Proportion

If a:b = c:d then:
a × d = b × c
Example:

2:3 = 4:6 because 2×6 = 3×4 = 12

Geometry

Area Formulas

Circle:
A = πr²
Triangle:
A = (1/2) × base × height
Rectangle:
A = length × width
Square:
A = side²

Perimeter Formulas

Circle (Circumference):
C = 2πr or πd
Rectangle:
P = 2(length + width)
Square:
P = 4 × side

Volume Formulas

Cube:
V = side³
Cuboid:
V = length × width × height
Sphere:
V = (4/3)πr³
Cylinder:
V = πr²h

Pythagoras Theorem

Formula:
a² + b² = c²
Where:

a, b = legs of right triangle, c = hypotenuse

Example:

3² + 4² = 5² → 9 + 16 = 25

Algebra

Quadratic Equation

Formula:
x = [-b ± √(b² - 4ac)] / 2a
For equation:

ax² + bx + c = 0

Algebraic Identities

(a + b)² = a² + 2ab + b²
(a - b)² = a² - 2ab + b²
a² - b² = (a + b)(a - b)
(a + b)³ = a³ + 3a²b + 3ab² + b³
(a - b)³ = a³ - 3a²b + 3ab² - b³

Exponents and Powers

a^m × a^n = a^(m+n)
a^m ÷ a^n = a^(m-n)
(a^m)^n = a^(mn)
a^0 = 1

Trigonometry

Basic Trigonometric Ratios

sin θ = Opposite / Hypotenuse
cos θ = Adjacent / Hypotenuse
tan θ = Opposite / Adjacent
Memory Trick:

SOH CAH TOA - Sin Opposite Hypotenuse, Cos Adjacent Hypotenuse, Tan Opposite Adjacent

Reciprocal Trigonometric Ratios

cosec θ = 1 / sin θ
sec θ = 1 / cos θ
cot θ = 1 / tan θ

Trigonometric Identities

sin²θ + cos²θ = 1
1 + tan²θ = sec²θ
1 + cot²θ = cosec²θ

Statistics (50+ Formulas)

Measures of Central Tendency

Mean = Σx / n
Median = Middle value (n odd: (n+1)/2th term, n even: avg of (n/2)th & (n/2+1)th)
Mode = Most frequently occurring value
Range = Maximum - Minimum

Measures of Dispersion

Variance = Σ(x - mean)² / n
Standard Deviation = √Variance
Coefficient of Variation = (SD / Mean) × 100
Quartile Deviation = (Q₃ - Q₁) / 2

Probability & Combinations

P(E) = Favorable Outcomes / Total Outcomes
P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
P(A ∩ B) = P(A) × P(B) [Independent]
nCr = n! / (r!(n-r)!)
nPr = n! / (n-r)!

Number System (40+ Formulas)

Properties & Operations

HCF (Highest Common Factor) - Largest common divisor
LCM (Least Common Multiple) = Product / HCF
a × b = HCF(a,b) × LCM(a,b)
Sum of n Natural Numbers = n(n+1)/2
Sum of n² = n(n+1)(2n+1)/6
Sum of n³ = [n(n+1)/2]²

Divisibility Rules

Divisible by 2: Last digit is even
Divisible by 3: Sum of digits is divisible by 3
Divisible by 4: Last 2 digits form number divisible by 4
Divisible by 5: Last digit is 0 or 5
Divisible by 9: Sum of digits is divisible by 9
Divisible by 11: Alternating sum of digits is divisible by 11

Mensuration (80+ Formulas)

2D Shapes - Area & Perimeter

Triangle:
Area = (1/2) × base × height | Perimeter = a + b + c
Heron's Formula: A = √[s(s-a)(s-b)(s-c)] where s = (a+b+c)/2
Rectangle:
Area = length × width | Perimeter = 2(l + w)
Diagonal = √(l² + w²)
Square:
Area = side² | Perimeter = 4 × side
Diagonal = side√2
Circle:
Area = πr² | Circumference = 2πr = πd
Arc length = (θ/360°) × 2πr
Sector area = (θ/360°) × πr²
Parallelogram:
Area = base × height | Perimeter = 2(a + b)
Rhombus:
Area = (1/2) × d₁ × d₂ | Perimeter = 4 × side
Trapezium:
Area = (1/2) × (sum of parallel sides) × height
Ellipse:
Area = πab | Perimeter ≈ π(a + b)

3D Shapes - Volume & Surface Area

Cube:
Volume = a³ | Surface Area = 6a² | Diagonal = a√3
Cuboid:
Volume = l × w × h | Surface Area = 2(lw + wh + hl)
Diagonal = √(l² + w² + h²)
Sphere:
Volume = (4/3)πr³ | Surface Area = 4πr²
Hemisphere:
Volume = (2/3)πr³ | Curved SA = 2πr² | Total SA = 3πr²
Cylinder:
Volume = πr²h | Curved SA = 2πrh | Total SA = 2πr(r + h)
Cone:
Volume = (1/3)πr²h | Curved SA = πrl | Total SA = πr(r + l)
Prism:
Volume = Base Area × height
Pyramid:
Volume = (1/3) × Base Area × height

Calculus Basics (60+ Formulas)

Limits & Derivatives

d/dx(xⁿ) = nxⁿ⁻¹
d/dx(sin x) = cos x
d/dx(cos x) = -sin x
d/dx(tan x) = sec²x
d/dx(eˣ) = eˣ
d/dx(ln x) = 1/x
d/dx(aˣ) = aˣ ln a
Product Rule: d/dx(uv) = u(dv/dx) + v(du/dx)
Quotient Rule: d/dx(u/v) = [v(du/dx) - u(dv/dx)] / v²
Chain Rule: dy/dx = (dy/du)(du/dx)

Integration Formulas

∫xⁿ dx = xⁿ⁺¹/(n+1) + C (n ≠ -1)
∫sin x dx = -cos x + C
∫cos x dx = sin x + C
∫sec²x dx = tan x + C
∫eˣ dx = eˣ + C
∫(1/x) dx = ln|x| + C

Sets & Relations (50+ Formulas)

Set Operations

n(A ∪ B) = n(A) + n(B) - n(A ∩ B)
n(A ∪ B ∪ C) = n(A) + n(B) + n(C) - n(A ∩ B) - n(B ∩ C) - n(A ∩ C) + n(A ∩ B ∩ C)
(A ∪ B)' = A' ∩ B' (De Morgan's Law)
(A ∩ B)' = A' ∪ B' (De Morgan's Law)
A - B = A ∩ B'

Sequences & Series (70+ Formulas)

Arithmetic Progression (AP)

nth term: aₙ = a + (n-1)d
Sum of n terms: Sₙ = n/2[2a + (n-1)d] or Sₙ = n/2(a + l)
Sum of AP: Sₙ = n/2[first term + last term]

Geometric Progression (GP)

nth term: aₙ = a × rⁿ⁻¹
Sum of n terms: Sₙ = a(rⁿ - 1)/(r - 1) where r ≠ 1
Sum of infinite GP: S∞ = a/(1 - r) where |r| < 1

Harmonic Progression

HP is reciprocal of AP
If a, b, c are in HP then b = 2ac/(a+c)

Logarithms (40+ Formulas)

Logarithm Laws

log(AB) = log A + log B
log(A/B) = log A - log B
log(Aⁿ) = n × log A
log_a b = log b / log a (Change of base)
a^(log_a x) = x
log_a a = 1 and log_a 1 = 0
log_a(1/b) = -log_a b

Coordinate Geometry (60+ Formulas)

Distance & Section Formula

Distance = √[(x₂-x₁)² + (y₂-y₁)²]
Midpoint = [(x₁+x₂)/2, (y₁+y₂)/2]
Section Formula: P = [(mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n)]
Centroid of Triangle: G = [(x₁+x₂+x₃)/3, (y₁+y₂+y₃)/3]

Straight Lines

Slope m = (y₂-y₁)/(x₂-x₁)
Equation: y - y₁ = m(x - x₁) (Point-Slope)
Slope-Intercept: y = mx + c
Intercept form: x/a + y/b = 1
General form: Ax + By + C = 0
Distance from point to line: |Ax₀+By₀+C|/√(A²+B²)

Circles & Conics

Circle: (x-h)² + (y-k)² = r²
General: x² + y² + 2gx + 2fy + c = 0
Parabola: y² = 4ax
Ellipse: x²/a² + y²/b² = 1
Hyperbola: x²/a² - y²/b² = 1

Binomial Theorem (30+ Formulas)

Binomial Expansion

(a+b)ⁿ = Σ nCr aⁿ⁻ʳ bʳ
General term: Tᵣ₊₁ = nCr aⁿ⁻ʳ bʳ
(1+x)ⁿ = 1 + nx + n(n-1)x²/2! + ...
(a+b)² = a² + 2ab + b²
(a+b)³ = a³ + 3a²b + 3ab² + b³
